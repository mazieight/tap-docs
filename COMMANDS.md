## 🆕 New Commands Added to Help

### 🤖 Bot Profile Commands (Owner Only)
These commands change the bot's actual Discord profile:

- `.t setbotavatar <file/url>` - Change bot's Discord avatar
- `.t setbotbanner <file/url>` - Change bot's Discord banner  
- `.t setavatar <file/url>` - Set room embed avatar
- `.t setbanner <file/url>` - Set room embed banner

### 🎤 Voice Connection Commands (Owner Only)
24/7 voice presence management:

- `.t vjoin` - Join your current voice channel and stay 24/7
- `.t vjoin <channel>` - Join specific voice channel by name
- `.t vleave` - Disconnect from current voice channel
- `.t vstatus` - Check current voice connection status

### 👑 Owner Management Commands (Owner Only)
Complete user permission management system:

- `.t addowner @user` - Add room owner
- `.t removeowner @user` - Remove owner  
- `.t listowner` - List all owners
- `.t addadmin @user` - Add admin
- `.t removeadmin @user` - Remove admin
- `.t listadmin` - List all admins
- `.t clearowners` - Remove all owners
- `.t clearadmins` - Remove all admins
- `.t setchannellog #channel` - Set comprehensive activity log channel

### 🎨 Appearance Commands (Owner Only)
Role and visual customization:

- `.t setrolevip @role` - Set VIP role
- `.t setroleadmin @role` - Set admin role

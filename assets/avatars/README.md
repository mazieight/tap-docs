Sample avatar files for OneTab bot.

To test the new setbotavatar command:

1. Add image files (.png, .jpg, .gif, .webp) to this folder
2. Use: .t setbotavatar <filename>
3. Or use: .t setbotavatar <url>
4. Or upload attachment with: .t setbotavatar

Example files you can add:
- neural_bot.png
- quantum_avatar.jpg  
- cyber_bot.gif
- futuristic_avatar.webp

Requirements:
- Max 8MB (Discord limit)
- Recommended: 512x512 or 1024x1024 pixels

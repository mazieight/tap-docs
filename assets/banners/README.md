Sample banner files for OneTab bot.

To test the new setbotbanner command:

1. Add image files (.png, .jpg, .gif, .webp) to this folder
2. Use: .t setbotbanner <filename>
3. Or use: .t setbotbanner <url>
4. Or upload attachment with: .t setbotbanner

Example files you can add:
- neural_banner.png
- quantum_header.jpg  
- cyber_banner.gif
- futuristic_header.webp

Requirements:
- Max 8MB (Discord limit)
- Recommended: 1920x1080 or 1600x640 pixels
- Note: Banner requires Discord Premium/Nitro for the bot

Popular banner sizes:
- 1920x1080 (16:9 ratio)
- 1600x640 (2.5:1 ratio)
- 1280x720 (16:9 ratio)
